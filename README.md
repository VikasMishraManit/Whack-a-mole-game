# Whac-a-Mole Game 🎮

A classic Whac-a-Mole arcade game built with vanilla JavaScript, HTML, and CSS. Test your reflexes by clicking on moles while avoiding the dangerous piranha plants!

## 🎯 Game Description

In this Mario-themed Whac-a-Mole game, players must click on Monty Moles as they pop up from pipes to earn points, while avoiding clicking on Piranha Plants which will end the game.

## 🎮 How to Play

1. **Start the game** - Moles and plants will automatically start appearing in random pipes
2. **Click the moles** - Each mole clicked gives you 10 points
3. **Avoid the plants** - Clicking a Piranha Plant ends the game
4. **Beat your high score** - Try to score as high as possible before hitting a plant!

## 🕹️ Game Mechanics

- **Moles** appear every 1 second in random pipes
- **Piranha Plants** appear every 2 seconds in random pipes
- **Scoring**: +10 points per mole clicked
- **Game Over**: Clicking a Piranha Plant ends the game

## 🛠️ Technical Features

- Pure vanilla JavaScript (no frameworks)
- 3x3 grid layout with 9 pipes
- Random spawn mechanics to prevent overlapping
- Real-time score tracking
- Game over state management
